# Rewrite Short Script Prompt

Rewrite the source into a Chinese short-video script.

Requirements:
- Do not translate sentence by sentence.
- Do not reuse the original narrative structure mechanically.
- Add context useful for Chinese audiences.
- Mark uncertain claims with 待核查.
- Avoid relying on original video footage.

Return markdown sections:
- 标题
- 口播稿
- 分镜建议
- 屏幕文字
- 风险点
- 待核查内容
